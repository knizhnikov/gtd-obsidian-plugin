# GTD Lite для Obsidian

Лёгкий плагин для работы по GTD: быстрый захват, разбор входящих, списки по зонам внимания, еженедельный обзор.

## Формат задач

Задачи — обычные чекбоксы в любых заметках:

```markdown
- [ ] Позвонить Ивану @phone #next
- [ ] Ответ от дизайнера @Мария #waiting
- [ ] Выучить испанский #someday
- [ ] Сдать отчёт @computer #next 📅 2026-10-20
```

Сроки — в формате плагина [Tasks](https://github.com/obsidian-tasks-group/obsidian-tasks) (`📅 ГГГГ-ММ-ДД`),
при выполнении добавляется `✅ ГГГГ-ММ-ДД`. В панели показываются только задачи с GTD-тегами.

- **Входящие** — `GTD/Inbox.md`
- **Действия вне проектов** (next / waiting / someday) — `GTD/Actions.md`
- **Справочное** — `GTD/Reference.md`
- **Проекты** — заметки в `GTD/Projects/`; задачи внутри относятся к проекту.
  Проект с `status: done` во frontmatter скрывается. Проект без `#next` подсвечивается как «застрявший».
- `@слово` — **зона внимания**: сфера, к которой относится действие (@работа, @дом, @здоровье…)
- Пути, теги и зоны внимания меняются в настройках плагина

## Команды

| Команда | Что делает |
|---|---|
| Захватить во входящие | Модалка: ввести мысль → Enter → строка в Inbox |
| Разобрать входящие | Мастер по каждому пункту: сделать сейчас / действие / ожидание / проект / когда-нибудь / справочное / удалить (клавиши 1–7, 0 — пропустить) |
| Знакомство и настройка | Пошаговый рассказ о GTD + первичная настройка: первые мысли во входящие, зоны внимания, проекты. Запускается сам при первом включении в пустом vault |
| Открыть панель GTD | Боковая панель: входящие, сроки, действия по зонам внимания, ожидание, проекты, когда-нибудь |

## Захват из любого места (даже когда Obsidian закрыт)

Плагин понимает ссылку `obsidian://gtd-capture`:

| Ссылка | Что делает |
|---|---|
| `obsidian://gtd-capture?vault=ИмяVault` | Открывает окно «Добавить во входящие» |
| `obsidian://gtd-capture?vault=ИмяVault&text=Позвонить%20Ивану` | Сразу сохраняет текст во входящие |

Если Obsidian закрыт, ссылка запустит его. Ссылку для своего vault можно скопировать в настройках плагина.

### Глобальная клавиша на macOS — «Быстрые команды»

**Вариант А: открыть окно захвата** (проще)

1. Откройте «Быстрые команды» → **＋** (новая команда), назовите «GTD: во входящие».
2. Добавьте действие **«Открыть URL-адреса»**, вставьте ссылку из настроек плагина: `obsidian://gtd-capture?vault=ИмяVault`.
3. Справа ⓘ (Сведения о команде) → **Добавить сочетание клавиш** → например `Ctrl+Option+Space`.

**Вариант Б: ввести мысль в системном окне, не переключаясь в Obsidian**

1. Действие **«Запросить ввод»** (Текст), вопрос: «Что у тебя в голове?»
2. Действие **«Закодировать URL»** — на вход «Введённый текст».
3. Действие **«Открыть URL-адреса»**: `obsidian://gtd-capture?vault=ИмяVault&text=` и в конец вставьте переменную «Закодированный URL».
4. Назначьте сочетание клавиш, как в варианте А.

### Windows

Создайте ярлык на рабочем столе: ПКМ → Создать → Ярлык → `obsidian://gtd-capture?vault=ИмяVault`.
Затем ПКМ по ярлыку → Свойства → «Быстрый вызов» → например `Ctrl+Alt+I`.

## Установка через BRAT

1. Obsidian → Настройки → Сторонние плагины → Обзор → найти **BRAT** → установить и включить.
2. Палитра команд (`Cmd/Ctrl+P`) → **BRAT: Add a beta plugin for testing**.
3. Вставить адрес репозитория: `https://github.com/knizhnikov/gtd-obsidian-plugin` → Add Plugin.
4. Настройки → Сторонние плагины → включить **GTD Lite**.
5. Захват во входящие — `Cmd+Shift+A` (Windows/Linux: `Ctrl+Shift+A`). Сменить: Настройки → Горячие клавиши → «GTD Lite».

Обновления BRAT подтягивает сам (при старте Obsidian или командой «BRAT: Check for updates»).

## Разработка

```bash
npm install
npm run install-vault -- "/путь/к/вашему/vault"   # симлинки в .obsidian/plugins/gtd-lite
npm run dev                                       # пересборка при изменениях
```

Чтобы плагин перезагружался без перезапуска Obsidian, поставьте в этот vault плагин
[Hot-Reload](https://github.com/pjeby/hot-reload) (через BRAT: `pjeby/hot-reload`).

## Выпуск новой версии

```bash
npm version patch        # 0.1.0 → 0.1.1: обновит manifest.json, versions.json, создаст коммит и тег
git push --follow-tags   # GitHub Action соберёт и опубликует релиз
```

Через ~1 минуту релиз появится на GitHub, и BRAT подтянет обновление.
